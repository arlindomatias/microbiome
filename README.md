# microbiome

Microbiome data analysis projects.

- [ptx_rats_emtab13426](ptx_rats_emtab13426): Snakemake + R Markdown 16S rRNA (V3-V4) pipeline (cutadapt, DADA2, SILVA 138.2, phyloseq, DESeq2/ANCOM-BC2) re-analysing gut microbiota of paclitaxel-treated rats (E-MTAB-13426) from raw reads.

History of this repository was split out of [arlindomatias/projects](https://github.com/arlindomatias/projects).
